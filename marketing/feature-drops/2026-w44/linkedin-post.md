Lleverage Feature Drop Week #44 🎁

Tom is out sick. Three supplier invoices are stuck halfway through their workflow, all waiting on him.

Until now, you'd reassign them step by step, and the next step would land right back with Tom. This week one click hands Mila the rest of the run.

That was the theme of the week: everything that makes a process stall. The person who's away, the PO number nobody filled in, the run that broke halfway. In an autonomous back office the agents do the routine work, but a process is only as fast as its slowest hand-off. So we went after the hand-offs.

When a workflow the Agent runs needs a PO number, it asks you on a card in the chat, and the same run carries on. When a run breaks halfway, Continue picks it up where it stopped, with everything it already did. And an Agent step in a workflow can save what it finds to the project's files.

My favourite: Continue. A tripped run used to mean starting over.

Plus stacked bar charts, date metrics and more. Full changelog in the comments.

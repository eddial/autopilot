Lleverage Feature Drop Week #48 🎁

Good week: pages in Lleverage now work like a document. You type straight onto the page, drop a table or a chart between the lines, and ask the Agent to build a new page for you.

In an autonomous back office the agents handle the orders and invoices that can run on their own, and people step in for the decisions. Every company runs that work its own way, so the system has to be shaped by the people who run it, and they need to correct it the moment something's off.

So this week is also about steering. You can edit your message while the Agent is still working, and it starts again with the new words. You can point at a spot in a report the Agent made and tell it what to change there. Schedules only run when there's something new, and an empty page offers to set itself up with the Agent. And more.

My favourite: pointing at the report. No more "the third column, second table from the top".

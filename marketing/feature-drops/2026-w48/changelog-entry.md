## Week 48: pages you write and shape yourself, and more ways to steer the Agent

{% embed url="https://www.youtube.com/watch?v=ZGiB_h7IY9o" %}

Pages now work like a document: you type on them, add blocks between the lines, and the Agent can make a new page for you. A live widget can be changed by hand in a form, and a data table can show its records on a timeline. You can also correct the Agent while it works, point at the exact spot in a report it made, and let schedules run only when there is something new.

### New features

* **Write a page like a document.** Pages and the Overview edit in place: type on any line, and press **/** for a block, such as a **Callout**, a **Table**, a **File**, an **App** or a chart the Agent builds. Point at a block for its **+** and its handle, and drag it beside another block to share the row, up to six side by side. Each page has its own lock, so a finished page stays as it is. [Pages](https://docs.lleverage.ai/run-operations/overview/pages)
* **Ask the Agent for a new page.** Ask the Agent for a dashboard, for example the orders waiting on a PO per customer, and it creates a page in Pages and builds on it, with text, numbers and charts. Its answer links to the page, and the link opens the page beside the chat. A locked page stops the Agent from changing it. [Pages](https://docs.lleverage.ai/run-operations/overview/pages)
* **Change a live widget yourself.** A live widget that reads a data table has **Edit widget** in its **Settings**. It opens a form: what the widget counts or adds up, such as **Total of Amount**, what it is **Grouped by**, the chart and the date range, with a preview that follows each choice. **Save** puts the change on the page. Asking the Agent stays one click away with **Chat with agent**. [Live widgets](https://docs.lleverage.ai/run-operations/overview/live-widgets)
* **See a table's records on a timeline.** In a data table's **Columns** window, set **View** to **Timeline**: each record becomes a bar between two dates, for example an order from its order date to its delivery date. Pick the **Lanes**, such as one per customer, the **Colour**, such as the status, and the **Time scale**. Drag a bar to move its dates, or drag an edge to change one of them. The **Table** block on a page can show the same timeline. [Tables](https://docs.lleverage.ai/build-and-improve/intelligence/tables)
* **Edit your message while the Agent works.** **Edit**, the pencil under your message, works while the Agent is still working on it. Saving a change stops the run and sends the new words, for example to leave out a customer whose account is on hold. [Chat and sessions](https://docs.lleverage.ai/run-operations/agent/chat-and-sessions)
* **Point at a spot and tell the Agent.** When the Agent hands back an HTML page or a PDF, such as a weekly order report, turn on notes in the file panel's header and click a spot or select text. Write what should change there and press **Send to agent**: the note goes to the Agent with the spot quoted, and the pin clears once it has replied. [Session workspace](https://docs.lleverage.ai/run-operations/agent/session-workspace)
* **Run a schedule only when something is new.** A schedule can watch new requests and your data tables, under **Run only when something is new**. Before each run it checks them; with nothing added or changed since the last run, the run is skipped and starts no Agent session. **Recent runs** lists each one, and a skipped run says "Nothing new since" with the time it checked from. [Schedules](https://docs.lleverage.ai/administer-and-govern/control/schedules)

### Improvements

* **Incognito chats.** The ghost button on a new Agent chat opens an incognito chat. It stays out of your history, saves nothing to memory, and is deleted when you close it with the cross.
* **Sort your pins into sections.** Right-click a pin to **Rename** it in place, change or remove its icon, or **Move to section**, with **New section…** to start one. Sections fold away and remember whether you left them open.
* **More charts and date ranges.** Live widgets can be an area chart, a scatter, a list or a progress bar against a goal. Every widget offers the same date ranges, with **This quarter**, **Last quarter**, **This week**, **Last week** and **Yesterday** among them. Ask the Agent for a widget that groups dates into age bands, such as 0 to 30 days, groups by a field on a linked record, or shows a tracked metric. [Live widgets](https://docs.lleverage.ai/run-operations/overview/live-widgets)
* **Set up an empty page with the Agent.** An empty Workflows, Data tables, Skills, Knowledge, Files or Apps page says what it is for and offers starters, such as **Import Data** and **Use a Template** on Data tables. **Set this up with the agent** opens the Agent beside the page with the request already written.
* **Projects are now workspaces.** The app, emails and the Agent say workspace. Owners decide whether members can create workspaces, under **Members can create workspaces** in Organisation Settings.
* **Edit many schedules at once.** In Schedules, tick several schedules for **Edit selected**, **Pause** or **Resume**. The edit changes only the session, status or time zone you set. A schedule's finished runs move to **Completed** on their own, and a failed run shows as **Failed**. [Schedules](https://docs.lleverage.ai/administer-and-govern/control/schedules)
* **Take a tour of the Agent.** People new to the Agent get **Take the tour** on the agent page: short stops you try for real, each with a message to send and **Next Step** to move on. When you invite someone, **Getting started** sets whether they take the tour, go straight to work or start with a skill.
* **An Overview page for each role.** Where a workspace had a different Overview per role, each version is now a page of its own, pinned at the top for that role. In Members, Roles, each role lists its pages with a switch. [Roles and permissions](https://docs.lleverage.ai/administer-and-govern/control/members/roles-and-permissions)
* **Close the page, keep the Agent.** With the Agent open beside a page, **Close page** in the page's header closes the page and gives the Agent the full width. A page also shows how many of your chats used it, next to its title.
* **Notifications you can clear.** The Notifications panel has **Mark all as read**, read and unread per notification, and selecting several at once. The bell shows a dot when something is unread. You can also turn off emails from one workspace, under **Emails by workspace** in your notification settings.
* **Files that play and open in place.** Audio and video files play where they are shown, in requests, Files, the Agent's file panel and data table records. PDFs open in a calmer reader with one bar of controls, Excel attachments in a request open in their own window, and an email attachment shows the whole thread.
* **More in data tables.** Right-click a row or card for **Open Full Page**, **Open in New Tab** and **Copy Link**. A table field on a form can tint the rows that match a rule, under **Highlight rows when**.
* **More.** A new icon set across the app. One **Help** button in the navigation, with **Report an issue** and **Chat with us**. Hide workspaces you don't use in the workspace switcher. Workspace Members lists invites **Waiting to join**, with **Resend**. Owners see AI usage by member and workspace under **Plan & usage**. The Agent and workflows can search an Outlook Online Archive. Drop files anywhere in the Agent chat. Email triggers can hand over the email as an .eml file. New chats start on Claude Sonnet 5.5, and GPT-6.2 Sol joins the model pickers. The Agent step in workflows is the **Lleverage Agent**. Requests show up to ten files as separate cards.

### Fixes

* A workflow needs a trigger before it can be published: **Publish** says so instead of publishing a workflow that can never start.
* Sorting a data table by a number field sorts by value.
* **Approve all** and **Deny all** stay in view on a long approval in the chat, and charts on a page keep their height.
* The workflow editor says why a save was refused, and **Create Test** works on a run whose form or trigger step was renamed since.
* Deleting a loop or Run Subworkflow step keeps its subworkflow while another step can still run it.
* A variable that a connection uses can't be deleted until the connection is disconnected.
* HTML dashboard widgets no longer turn black in dark mode, and the workflow runs usage email shows the right share of your allowance.

Talk to Llev

Voice in the agent. You say what you want and Llev makes the change in the platform, then answers questions about the work. Easiest to show, and clearly unlike assistants that only suggest.

20s · 4:5#change-log 25 Sep
Company post

Most AI assistants tell you what to click. Then you go and click it. Llev doesn't. Press the mic in the agent and say "add a chart of last month's runs, split by outcome". The chart is on your Overview page. Ask "when did the last run fail?" and you get the run, the reason and who has it. Cut it off mid-sentence and it stops and listens. Everything you said lands in the chat transcript. Talk to Llev is live now in the Lleverage agent.

Board view for data tables

Any data table switches from grid to board. Drag a card to another lane and the record updates. Very visual, and it shows Lleverage as the team's workspace, not a chat window.

18s · 4:5#change-log 23 Sep
Company post

An accounts payable team doesn't think in rows. They think in "waiting for a PO", "ready to match" and "approved". Every data table in Lleverage now has a board view. Switch from grid to board in the table header, pick a column to group by, and each record becomes a card. Drag a card to another lane and the record updates. Group by status, person, select or yes/no columns. Choose which fields show on each card. Same data, in the view the team actually works in.

Skill tests

The agent writes tests for a skill, runs them, reads why one failed and fixes the instructions. Supports two differentiators: built for messy reality, and the path from coworker to autonomous.

20s · 4:5#change-log 25 Sep
Company post

The person who builds an AI skill usually ends up as its test suite. Every change, they re-run the same ten orders by hand. In Lleverage, the agent writes tests for a skill, runs them, reads why one failed and changes the skill. Then it runs them again. In the clip, a purchase order skill fails on an order without a PO number. The model took one from the email subject. The fix isn't a looser test. It's one line in the instructions: never infer a PO number, hand the order to purchasing. Skill tests are live, no feature flag.

Personal post · draft for Badr

Build for the champions.

Pairs with the Skill tests clip

AI adoption isn't stuck because the models are weak. It's stuck because most AI tools need every employee to become an AI enthusiast. That's not how operations teams work. A purchasing team has one or two people who will build a skill. The other eight want the order handled. So we build for the champions. They build a skill, the agent writes tests for it, and it reaches the rest of the team once it passes. When a test fails, the agent shows why and fixes the instructions, not the test. Start as a coworker. Promote it to run on its own once the tests and the monitoring say it's ready. That's the loop we shipped this week.

## Feature Drop · Week 42

{% embed url="feature-drop-2026-w42.mp4" %}
Seven new things in Lleverage, shipped 2–9 October.
{% endembed %}

### Projects: the Agent sets up your project

Start a new project from one of six processes, such as Quote & Sell or Pay & Collect, or start blank. The Agent runs the setup with you as a plan you can follow: it connects your systems and reads them before it asks you anything, adds the team, writes its instructions, and hands over the first jobs. It finishes with your project's Overview. [Projects and solutions](../understand-lleverage/readme/projects-and-solutions.md)

### Overview: the Agent builds your dashboards

Ask the Agent for what you need to see, for example "orders waiting on a PO and handling time per day", and it adds the widgets to your Overview, reading your live data. Ask again to change them. Each role can have its own version of the Overview, and a Table widget can show any saved view of a data table.

### Workflows: the Agent builds and fixes workflows

Open the Agent beside the canvas while you work on a workflow and ask for a change, such as "check each line's price against our price agreements". It already knows the workflow you have open, and the steps it changes light up. It can run the workflow again after a fix, and it asks you before it puts a workflow live. [Build a workflow](../build-and-improve/automate/build-a-workflow/README.md)

### Agent: talk to the Agent while it builds

Start a voice call with the Agent and talk it through: build a workflow, a dashboard or a whole project just by talking. Open any page in the project and the call comes with you, and the Agent tells you what it's finding while it works. It also offers a call when it needs a lot from you. [Call with Agent](../run-operations/agent/call-with-agent.md)

### Workflows: put the Agent to work inside a workflow

Add the Agent as a step in any workflow and describe the job in plain words. It can use any Skill or integration you can use yourself, and each time the workflow runs, it does that job in the background. When something is missing, such as a PO number, it asks a person. [Agent step](../build-and-improve/automate/advanced-workflow-building/agent.md)

### Data tables: work through records on a board

Show a data table as a board, with a lane for each status. Drag a card to the next lane and the record's status changes with it; open a card for the full record. Linked records show by name, number columns can show as progress bars, and **Reset to view** puts the fields on a card back to how the saved view shows them. [Tables](../build-and-improve/intelligence/tables.md)

### Skills: Skills that improve from how they're used

A Skill is how the Agent does one job, such as reading purchase orders. Its **Feedback** tab collects every rating on work where it was used; filter to the negative ones and choose **Improve with agent**, and the Agent drafts a change for you to approve. The **Versions** tab lets you browse, revert and unpublish versions. [Skills](../build-and-improve/intelligence/skills.md)

<summary>Also new</summary>

* **Type while the Agent works.** Send a message mid-task and the Agent takes it into the task it's on.
* **Hand the Agent your files.** Up to 50 files per message, Excel files shown as a real spreadsheet, and Google Drive folders connected to Project Files and kept in sync.
* **Know what the Agent made.** The Agent sidebar lists everything the Agent created in the session, and the Agent links straight to the pages it means.
* **Decide with the full picture.** Zoom into a request's attachments and click through them; in Apps, **Edit and resubmit** corrects a form you already sent.
* **Team and access in one place.** Members and Roles tabs with a simpler role editor, seats and invites as one self-serve flow, and with single sign-on, invites only to your company's domains.
* **Claude Haiku 5.5 for quick steps.** Choose **Fastest** in any model picker.
